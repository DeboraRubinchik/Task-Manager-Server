# Task-Manager-Server
This is the backend for the Task Manager application that I developed for the home assignment, built with .NET 8 Web API.

Technologies I Used:
- C#
- ASP.NET Core 8.0
- JSON File Storage for persistence.

Requirements:
- .NET 8 SDK installed on your machine.
- You can install it from here -> https://dotnet.microsoft.com/en-us/download/dotnet/8.0

How to Run the server:
1. Clone the repository or download the files.
2. Open a terminal in the project directory - TaskManagerServerCS.
3. Build the project:
   ```bash
   dotnet build
4. Run the application:
   ```bash
   dotnet run
